O link acima, está o meu trabalho desenvolvido no postman, onde utilizei a url: https://serverest.dev, que é uma API REST gratuita que simula uma loja virtual. Utilizei uma requisição GET /produtos para buscar produtos da ServeRest, criei um post/ usuarios para criar o meu usuário, logo depois utilizei um post/login para realizar a autenticação, com isso meu login foi criado corretamente, gerando o token de acesso, tornando-se tudo certo. E também acrescentando ao meu trabalho criei um post/produtos, que cria um novo produto, realizando a consulta do produto pelo seu ID. Por fim, utilizei o delete/produtos colocando o id do produto criado, para testar a exclusão dele.
