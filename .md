# Consumindo a API do ReqRes com Python

## Introdução

O **ReqRes** é uma plataforma gratuita criada para desenvolvedores aprenderem e testarem integrações com APIs REST.

Ela simula um sistema real de gerenciamento de usuários, permitindo realizar consultas, autenticação, criação, atualização e exclusão de registros sem a necessidade de instalar um servidor ou criar um banco de dados.

É uma excelente ferramenta para aprender:

- APIs REST
- HTTP
- JSON
- Autenticação
- Python
- Postman
- FastAPI
- Integrações entre sistemas

A grande vantagem é que os dados já estão disponíveis na plataforma, permitindo focar apenas no desenvolvimento da integração.

---

# O que é uma API REST?

Uma API (Application Programming Interface) é uma interface que permite que dois sistemas troquem informações.

No caso do ReqRes, nossa aplicação envia uma requisição HTTP para a plataforma.

A plataforma processa a solicitação e devolve uma resposta em formato JSON.

```
Python
      │
      │ HTTP
      ▼
ReqRes API
      │
      ▼
JSON
      │
      ▼
Aplicação Python
```

# Criando uma conta

Acesse:

https://app.reqres.in/

Crie uma conta gratuita.

Após realizar o cadastro, será gerada uma chave de API (**API Key**).

Essa chave será utilizada em todas as requisições.

Exemplo:

```
x-api-key: SUA_CHAVE
```

Sem essa chave a API retornará erro de autenticação.

# Consumindo a API em Python

Primeiro instale o Requests.

```bash
pip install requests
```

---

## Exemplo 1

Consultar usuários

```python
import requests

url = "https://reqres.in/api/users?page=2"

headers = {
    "x-api-key": "SUA_API_KEY"
}

response = requests.get(
    url,
    headers=headers
)

print(response.status_code)

dados = response.json()

print(dados)
```

---

## Exemplo 2

Percorrendo os usuários

```python
import requests

url = "https://reqres.in/api/users?page=2"

headers = {
    "x-api-key": "SUA_API_KEY"
}

response = requests.get(url, headers=headers)

dados = response.json()

for usuario in dados["data"]:

    print(usuario["id"])
    print(usuario["first_name"])
    print(usuario["last_name"])
    print(usuario["email"])
    print()
```

---

## Exemplo 3

Login

```python
import requests

url = "https://reqres.in/api/login"

headers = {
    "x-api-key": "SUA_API_KEY"
}

payload = {
    "email":"eve.holt@reqres.in",
    "password":"cityslicka"
}

response = requests.post(
    url,
    json=payload,
    headers=headers
)

print(response.status_code)

print(response.json())
```

# Tratando erros

Sempre verifique o código HTTP.

```python
if response.status_code == 200:

    print("Sucesso")

else:

    print("Erro")

    print(response.status_code)
```

---

# Principais códigos HTTP

| Código | Significado |
|---------|-------------|
| 200 | Sucesso |
| 201 | Registro criado |
| 204 | Exclusão realizada |
| 400 | Requisição inválida |
| 401 | Não autorizado |
| 404 | Recurso não encontrado |
| 500 | Erro interno |

---

# Boas práticas

- Nunca coloque a API Key diretamente no código.
- Utilize variáveis de ambiente.
- Valide o código HTTP.
- Trate exceções.
- Defina timeout nas requisições.
- Utilize `requests.Session()` quando realizar várias chamadas.
- Documente suas integrações.
